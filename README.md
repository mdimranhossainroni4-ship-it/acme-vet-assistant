# ACME VET Assistant

A bilingual (Bangla and English) veterinary information demo for searching common livestock diseases by animal, disease name, or symptom.

## Run locally

Open `index.html` in a web browser. No build tools or dependencies are required.

## Scope and safety

This demo provides general, preliminary information only. It is not a diagnosis or a substitute for a registered veterinarian. For severe symptoms or emergencies, contact a veterinarian promptly. Medicine information should be added only from verified sources.
